# Sweet Crumbs Bakery Landing Page

Sweet Crumbs is a responsive bakery landing page created using HTML5 and CSS3.

## Features

- Responsive navigation bar
- Attractive hero section
- Bakery product cards
- About us section
- Special offer section
- Contact and social media footer
- Responsive design for mobile and desktop
- Local bakery images

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Project Structure

Sweet-Crumbs-Landing-Page/
│
├── index.html
├── style.css
├── README.md
└── images/

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html`.
4. The website opens in a browser.
